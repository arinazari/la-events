# Weekend digests

One file per weekend, keyed by that weekend's **Friday**: `YYYY-MM-DD.md` (covers Fri–Sun,
with Thursday-night events folded in as a lead-in). Maintained daily by the routine in
`routines/daily-digest-prompt.md` for the next ~16 weekends (~4 months).

- `index.md` is the entry point — one row per weekend, soonest first.
- **Near weekends** (next ~6) are full digests, scored against `taste.yaml`.
- **Far weekends** (7–16 out) list only what's already announced / on sale, and fill in as
  they approach.
- Past weekends are dropped on each run.
