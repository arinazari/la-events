# Dr. Ganesan's LA Events Digest
*Digest regenerated Tue 7/14 — picks updated.*

Fair warning: this pull skews hard toward DTLA electronic/afterhours — thin on the standup, theater, and food pop-ups this profile is meant to cover, so treat it as a partial read until taste gets dialed in further.
