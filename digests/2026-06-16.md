## What changed this run

- **Added Filmbot/Nightjar cinema fetcher** (`scripts/fetch_filmbot.py`) — cracks the JS-rendered cinema problem by hitting the widget's backing REST API instead of running a browser (deterministic + cheap). **Vidiots now live** (~20 films/2wk w/ runtime, year, format, sold-out). Generalizes to any `nj/v1` cinema.
- **Added 19hz** (`scripts/fetch_19hz.py`) — the canonical LA dance calendar. ~200 events/2wk with price tiers, RSVP windows, organizer names. Biggest gain for your top category.
- **Added generic JSON-LD scraper** (`scripts/fetch_jsonld.py`) — correct + ready, but most LA venue sites (DICE, Lodge Room, Pantages, Zebulon) are JS-rendered with no static JSON-LD. Eventbrite serves Event JSON-LD but bot-walls fetches.
